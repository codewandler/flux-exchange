## Status

**v0.0.1 — a charter, a type system, and one route.** `crates/exchange-host` carries the vocabulary
and the rules as tested types, plus a bound credential store (32 tests); `crates/exchange-server`
binds loopback and answers `GET /health`, refusing a reachable bind with no identity (13 tests);
`console/` renders fixtures. **Everything past `/health` is still unbuilt.** See
[README](../../README.md) § Status.

**The one blocker worth knowing before you pick anything up.** `codewandler-connector-pack` 0.8.0
requires `codewandler-flux-runtime ^0.41`, which for a 0.x crate means `<0.42`. flux is at
**0.45.0**. Two flux-runtime versions are two incompatible types — `connector-pack` hands out
`Arc<dyn Tool>` — so the **`invoke` epic cannot start** until flux-connectors republishes against
the current engine line (X-11).

**What that does *not* block, which is most of the first wave:** `connector-catalog` has **zero
dependencies**, and `connector-spec` / `connector-secrets` carry **no flux dependency at all**. The
HTTP surface, sign-in, the catalogue and the credential store are all buildable today.
